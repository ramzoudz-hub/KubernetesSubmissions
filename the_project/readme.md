# The Project – Kubernetes Exercise 1.2


## 1. Build the Docker Image

First, we created a `Dockerfile` for our Node.js application.

Then, we built the Docker image locally:

```bash
docker build -t the-project .
```

The image is now available locally.

**Note:** We have two options for using the image:

- Push it to Docker Hub so it can be accessed remotely.
- Keep it locally and use it directly.

For this exercise, we decided to use the local image.

## 2. Create a Kubernetes Cluster

We used **k3d** to create a local Kubernetes cluster:

```bash
k3d cluster create mycluster
```

This creates a Kubernetes cluster named `mycluster`.&#x20;

but in my practice i created it first before anything else.

## 3. Run the Application as a Pod

Next, we deployed our application using `kubectl`:

```bash
kubectl run the-project --image=the-project:latest --image-pull-policy=Never
```

**Explanation:**

- `kubectl run`: Creates a Pod.
- `log-output`: The name of the Pod.
- `--image=log-output`: Specifies the Docker image.
- `--image-pull-policy=Never`: Tells Kubernetes to use the locally available image without trying to pull it from a registry.

## 4. Verify the Pod

To check whether our Pod is running:

```bash
kubectl get pods
```

If everything is working correctly, we should see the `the-project` Pod with a `Running` status.

## 5. Check Application Logs

Finally, we can inspect the logs generated by our Node.js application:

```bash
kubectl logs the-project
```

This allows us to see the output generated by the application inside the Pod.
